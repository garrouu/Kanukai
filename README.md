# KanuKai

Website jasa furniture: pembuatan dan perawatan furniture oleh pengrajin .
Dibuat dengan HTML, CSS, dan JavaScript (50% belum semuanya)

## Halaman
- `index.html` : Beranda (hero, layanan, pengrajin, cara kerja)
- `pembuatan.html` : Formulir pembuatan furniture
- `perawatan.html` : Formulir perawatan furniture

## Struktur folder
kanukai/
├── index.html
├── pembuatan.html
├── perawatan.html
├── style.css          (design semua tampilan)
├── js/
│   ├── pembuatan.js   (estimasi, cek kayu, pesan terkirim)
│   └── perawatan.js   (pesan terkirim)
└── images/            (hero.jpg, pembuatan.jpg, perawatan.jpg)


## Catatan
Web ini masih dalam tahap pengembangan, jadi masih belum bisa bekerja secara maksimal.
1. Formulir masih belum terhubung dengan server (Ketika di klik pesan terkirim, pesan belum bisa diterima)
2. Metode pembayaran belum dikembangkan
3. Profil pengrajin belum dikembangkan
4. Login & Search belum dikembangkan (masih tampilan saja)
5. Logo aplikasi
